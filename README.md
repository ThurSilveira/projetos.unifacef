# Projetos UniFACEF

Repositório central das disciplinas cursadas na UniFACEF.

## Mapa

- [`estrutura-dados`](./estrutura-dados): bibliotecas, testes, grafos, atividades e dados em JavaScript.
- [`paradigmas-programacao`](./paradigmas-programacao): exercícios Java, APIs Spring Boot e o projeto web UCE.

Cada disciplina possui um README próprio com a estrutura e os comandos de execução.

## Verificação rápida

```bash
cd estrutura-dados
npm test
npm run grafos
```
